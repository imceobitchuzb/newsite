# ⚡ NOVA — Fast, Beautiful & Universal Web Platform

> Современный, сверхбыстрый и универсальный веб-сайт для портфолио, IT-продукта, стартапа или креативного агентства.  
> Создан с нулевыми внешними зависимостями, поддержкой тем, двуязычием (RU / EN) и готовым деплоем на **GitHub Pages**.

---

## ✨ Ключевые особенности

- 🚀 **Максимальная производительность**: 100/100 в Google Lighthouse, мгновенная загрузка (<20ms).
- 🎨 **Эстетичный Glassmorphism**: дизайн в стиле Linear / Apple с мягким блюром, аккуратными градиентами и неоновой подсветкой.
- 🌌 **Живой фон с интерактивом**: мягко движущиеся градиентные сферы (Aurora Blobs) и лёгкие частицы Canvas, реагирующие на курсор мыши.
- 🎭 **Интерактивный движок тем**:
  - Переключение Тёмной / Светлой темы (Sun/Moon).
  - 4 цветовых акцента в реальном времени: `Cyan (Неон)`, `Violet (Электро)`, `Emerald (Изумруд)`, `Amber (Закат)`.
  - Автоматическое сохранение выбора в `localStorage`.
- 🌐 **Двуязычность на лету (RU / EN)**: переключение языка без перезагрузки страницы прямо из панели навигации.
- 📱 **100% адаптивность**: безупречный рендеринг на смартфонах, планшетах и широких мониторах.
- 🔍 **Фильтрация проектов**: интерактивная галерея работ с фильтром по категориям и подробными модальными окнами.
- 📈 **Анимированные счетчики**: плавная анимация цифр при скролле (Intersection Observer).
- 💬 **Форма обратной связи**: интерактивная отправка с валидацией полей и всплывающими тост-уведомлениями.
- 🛠 **Zero Build Steps**: чистый HTML5, современный CSS3 и модульный ES6+ JavaScript. Никаких `npm install` или поломок сборки.

## 🚀 Как включить сайт на GitHub Pages (Бесплатно)

Сайт полностью подготовлен к работе на GitHub Pages:

1. Откройте ваш репозиторий: **[github.com/imceobitchuzb/newsite](https://github.com/imceobitchuzb/newsite)**
2. Перейдите во вкладку **Settings** &rarr; слева выберите раздел **Pages**.
3. В выпадающем списке **Build and deployment**:
   - **Source**: выберите `Deploy from a branch` (или `GitHub Actions`).
   - **Branch**: выберите `main` и папку `/(root)`, затем нажмите **Save**.
4. Через 30-60 секунд ваш сайт будет доступен по ссылке:  
   👉 **`https://imceobitchuzb.github.io/newsite/`**

## 🎨 Кастомизация под себя

1. **Изменение текстов и переводов**:  
   Откройте файл `js/translations.js` и отредактируйте нужные фразы в блоках `ru` и `en`.
2. **Добавление своих проектов**:  
   - Добавьте или отредактируйте карточку в секции `#showcase` файла `index.html`.
   - Задайте подробное описание в объекте `projectDetails` файла `js/main.js`.
3. **Контакты и ссылки**:  
   В секции `#contact` и футере файла `index.html` укажите ваши актуальные соцсети, Telegram или почту.
